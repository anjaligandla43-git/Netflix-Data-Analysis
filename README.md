# Netflix Data Analysis

## Project Overview
This project analyzes Netflix Movies and TV Shows data using Python.

## Objectives
- Analyze Netflix content.
- Explore Movies and TV Shows.
- Identify content trends and patterns.
- Visualize data insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Dataset Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Conclusion

## Dataset
Netflix Movies and TV Shows Dataset.

## Conclusion
This project helped me understand data analysis, data cleaning, exploratory data analysis, and data visualization using Python.
